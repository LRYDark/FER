========================================================
  Forbach en Rose — Version 2.0.0
========================================================

⚠️ Après mise à jour : exécuter update.php une fois (admin connecté).
   Il migre la configuration vers le nouveau format chiffré puis
   supprime les fichiers devenus inutiles (config/.env, .env.example).

--------------------------------------------------------
CONFIGURATION CHIFFRÉE (nouveau — comme MERIDIAN)
--------------------------------------------------------
- Les secrets (identifiants BDD, ENCRYPTION_KEY) ne sont plus stockés
  en clair dans config/.env : ils sont chiffrés dans config/config.enc
  (AES-256-GCM), déchiffrable uniquement avec config/master.key.
  Les deux fichiers sont illisibles séparément et bloqués côté web.
- Nouvelles installations : install.php génère directement
  config.enc + master.key (plus aucun .env).
- Sites existants : migration AUTOMATIQUE au premier chargement de
  page (le .env est conservé tant qu'update.php n'a pas vérifié que
  la config chiffrée fonctionne, puis supprimé).
- ⚠️ SAUVEGARDE : conservez config/master.key ET config/config.enc
  dans vos sauvegardes — sans master.key, la config (et donc la clé
  de chiffrement des données personnelles) est irrécupérable.
- Déplacement de serveur : copier config/config.enc + config/master.key
  suffit (plus besoin de ressaisir l'ENCRYPTION_KEY).
- La clé peut être déplacée hors du webroot via la variable
  d'environnement FER_KEY_FILE.
- TRUSTED_PROXIES / APP_URL / SYNC_WORKER_TOKEN éventuels de l'ancien
  .env sont repris tels quels dans config.enc (aucune reconfiguration).

--------------------------------------------------------
CONNEXION PAR CLÉ D'ACCÈS DIRECTE (nouveau)
--------------------------------------------------------
- Sur la page de connexion : bouton « Se connecter avec une clé
  d'accès » dès le premier écran — plus besoin de saisir l'email.
  Le navigateur propose la clé enregistrée (empreinte, Windows Hello,
  clé Apple) et connecte directement.
- Les méthodes existantes sont conservées à l'identique : email +
  code mail, TOTP, mot de passe, et le flux passkey après saisie
  de l'email.

--------------------------------------------------------
NOUVELLE INTERFACE D'ADMINISTRATION (jr-theme)
--------------------------------------------------------
- Toute l'administration adopte le style jr-theme (MERIDIAN) :
  sidebar en carte flottante, menus groupés par sections (Pilotage,
  Inscriptions, Contenu, Emails, Réglages, Sécurité & système),
  bloc utilisateur en bas de la sidebar (profil, mode T-shirts,
  déconnexion).
- Les sous-menus des pages Réglages et Emails sont désormais dans
  la sidebar (un clic = le bon onglet directement).
- Réorganisation : l'onglet AssoConnect regroupe liaison, domaines
  CSP et tous les imports (les 2 anciens onglets Import fusionnés) ;
  la carte « QR Code dans les mails » rejoint le Template.
- Apparence PAR UTILISATEUR (profil → Apparence) : thème clair /
  sombre / système, couleur d'accent (rose du site par défaut,
  presets ou couleur libre), police de l'admin — indépendant du
  site public, qui garde son « Thème du site » (Réglages →
  Personnalisation).
- Pages de connexion, réinitialisation, changement de mot de passe,
  installation et mise à jour : layout « split » avec panneau
  illustré animé, aux couleurs de l'accent.
- Graphiques (Statistiques, Visites) réhabillés aux couleurs du
  thème (accent, clair/sombre automatiques).

--------------------------------------------------------
SÉCURITÉ
--------------------------------------------------------
- config/.htaccess et .htaccess racine : extensions .enc et .key
  bloquées côté web (master.key et config.enc jamais servis).
- Suppression du .env en clair uniquement après vérification par
  update.php que config.enc se déchiffre correctement.
- Anti-bruteforce sur la connexion par clé d'accès directe :
  5 tentatives max par session + auto-ban IP (même politique que
  les autres facteurs).
